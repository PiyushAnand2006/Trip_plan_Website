# Design System

## 1. Colors
- Primary: `#ff385c`
- On primary: `#ffffff`
- Backgrounds: `#ffffff`, `#f7f7f7`
- Surface: `#ffffff`
- Text primary: `#222222`
- Text secondary: `#717171`
- Border: `#dddddd`
- Shadow: `0 6px 20px rgba(0,0,0,0.08)`

## 2. Typography
- Font family: DM Sans
- Base size: 16px
- Heading scale: 32/28/24/20/18

## 3. Components
- Cards: rounded-2xl, soft shadow, image top, content bottom.
- Buttons: pill shape, primary filled, secondary outline.
- Chips: small rounded tags for filters.
- Carousel: horizontal scroll with snap and arrow buttons.

## 4. Layout
- Maxwidth container: 1200px
- Section padding: `60px 28px` desktop, `40px 20px` mobile.
- Grid gap: 24px

## 5. Imagery
- Unsplash images with `w=1200&h=800&fit=crop`.
- Lazy load images.

## 6. Accessibility
- All images need alt text.
- Interactive elements need focus-visible styles.
- Use semantic HTML where possible.
